# Netflix GPT 🎬

A modern Netflix clone built using React, Redux Toolkit, Firebase Authentication, and Tailwind CSS — enhanced with dynamic movie trailers using the TMDB API.

## ✨ Features

- 🔐 User Authentication (Sign In / Sign Up)
- 🎥 Real-time Movie Trailers from YouTube
- 🍿 Now Playing Movies using TMDB API
- 🔄 Global State Management with Redux Toolkit
- ⚡ Responsive UI with Tailwind CSS
- 🔍 Search and Browse Functionality (optional)

## 🚀 Tech Stack

- **React**
- **Redux Toolkit**
- **Firebase Auth**
- **Tailwind CSS**
- **TMDB API**
- **YouTube iFrame Player**
